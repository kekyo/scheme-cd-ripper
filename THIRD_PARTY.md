## Obtaining and rebuilding the source

When distributing binaries, publish the `cdrip-<version>-source.tar.xz` generated by the same build at the same download location.
It includes the Chafa and smolscale sources used in the build, the Scheme CD Ripper sources, and the build scripts.
`build.sh` creates it in `build/deb/` (or `deb/` under the selected `BUILD_DIR`); `build_package.sh` uses `artifacts/source/`.
Select the archive matching your binary version from the [official release location](https://github.com/kekyo/scheme-cd-ripper/releases).
GitHub's automatically generated Source code archives omit submodule contents and cannot substitute for this archive.

Extract into an empty directory and install the build dependencies listed in the README.
For a source distribution without Git history, set the `CDRIP_PACKAGE_VERSION` environment variable to the release version and run `./build.sh`.
The same steps rebuild the shared library after modifying the Chafa sources.

## Replacing the library

Place an interface-compatible modified `libchafa.so.0` in a directory of your choice and select it as follows, without relinking the CLI:

```bash
LD_LIBRARY_PATH=/path/to/modified-chafa/lib cdrip
```

Modification of Chafa and reverse engineering for debugging such modifications are not restricted.
